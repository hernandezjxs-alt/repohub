# RepoHub

Buscador de repositorios de GitHub. Funciona como una sola página web (`index.html`), sin servidor ni instalación.

## Qué hace
- Busca repositorios por estrellas, tema, lenguaje, actividad e idioma de la descripción (español o inglés).
- Muestra el Top 5 con más estrellas según los filtros activos.
- Sugiere colecciones de temas para Claude e IA, análisis de datos y automatización.
- Abre una ficha por repositorio con estadísticas, lenguajes y un resumen en español.
- Incluye una colección para encontrar skills y plugins de Claude.
- Busca a cualquier usuario u organización y muestra su ficha: repositorios, estrellas, lenguajes y temas.
- Con tu cuenta conectada: busca dentro del código, ejecuta consultas GraphQL prediseñadas y muestra tus estadísticas, tus amigos (seguimiento mutuo), seguidos, seguidores y repositorios favoritos.

## Cómo usarlo
Abre la página publicada o descarga `index.html` y ábrelo en tu navegador.

Para las funciones que necesitan cuenta, pulsa **Conectar con GitHub** y pega un token personal. El token se guarda solo en tu navegador y solo se envía a `api.github.com`. Nunca lo subas al repositorio.
