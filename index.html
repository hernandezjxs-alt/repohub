    Conecta tu cuenta de GitHub

    GitHub no permite iniciar sesión directo desde una página local, así que se usa un token personal. Se guarda solo en este navegador y se envía únicamente a api.github.com.

    1. Crea un token en GitHub. El enlace ya marca los permisos repo y read:user.
    2. Cópialo y pégalo aquí.

    Si prefieres dar menos permisos, usa un token que solo lea tus repositorios. No verás los privados.
